# Learning Angular by Building Equality Map

This is a series of lessons written while building **Equality Map**, a small web app
that shows an interactive world map colored by things like income inequality,
access to education, and other social indicators. You can click countries to
select them and see combined stats about your selection.

The lessons don't assume you know Angular. They **do** assume you're comfortable
with JavaScript (variables, functions, arrays, classes) — Angular adds a
structure and a set of tools on top of that, and that structure is what we're
here to learn.

Each lesson is short and builds on the one before it, in the same order the
app was actually built. Read them in order the first time through.
